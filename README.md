# 🚀 Cognify v1.0.0 — Initial Release

Welcome to the first official release of **Cognify**! 🎯  
A modern, dark-themed productivity and developer-focused task & sprint tracking application built with **Expo**, **React Native**, **Firebase**, and **NativeWind**.

---

### ✨ Highlights & Key Features

#### 📌 Task & Sprint Management
- **Dual Categories:** Organize your workflow into **Project** and **Learning** tracks.
- **Subtasks & Dynamic Progress:** Task progress percentage is calculated dynamically based on completed subtasks.
- **Flexible Deadlines:** Support for both dated and undated tasks (due dates are completely optional).
- **Attachments & Media:** Upload architecture diagrams, ERDs, and screenshots directly using **Cloudinary**.
- **Engineering Notes:** Keep technical notes, session storage configs, and architectural memos right inside task details.

#### 📅 Interactive Calendar & Planner
- **Monthly Overview:** Visual dot indicators for Projects, Learning paths, and Completed tasks.
- **Daily Focus Schedule:** Plan your focus blocks and review tasks scheduled for any selected date.
- **Undated Tasks Vault:** Dedicated accordion drawer to quickly assign unscheduled tasks to any day.

#### 📚 Knowledge Vault & Notes
- **Rich Note Taking:** Capture learning takeaways, summaries, and cheat sheets.
- **Live Link Previews:** Paste any external technical article link to generate a rich card preview.
- **Media Gallery:** Image attachments with full-screen zoom preview.
- **Tag Filtering:** Filter knowledge snippets effortlessly with tags (e.g., `#backend`, `#typescript`).

#### 🎨 Design & Experience
- **Raycast/Linear Inspired Dark UI:** Clean, distraction-free aesthetic built with **NativeWind (Tailwind CSS)**.
- **Realtime Sync:** Powered by **Firebase Authentication** and **Cloud Firestore**.

---

### 🛠️ Tech Stack
- **Framework:** Expo & React Native (TypeScript)
- **Navigation:** Expo Router
- **Styling:** NativeWind (Tailwind CSS)
- **Backend & Auth:** Firebase Authentication & Firestore
- **Media Storage:** Cloudinary REST API
- **Icons:** Lucide React Native
